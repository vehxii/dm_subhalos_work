<ins>This repository contains:</ins>

1. Current work with Dr. Ethan O. Nadler, postdoc Dr. Sandip Roy, and undergraduate student Roxanne Lai (all at UC San Diego) on a project studying the connection between subhalo counts and dark matter mass accretion.
   Branches focus on different aspects of this project:
   a. "host_mass-subhalo_population-correlation" contains Jupyter Notebooks showing past & current progress on describing this correlation over time.
   b. "global_plotting_function" contains Jupyter Notebooks showing past & current progress on creating an automatic pipeline for creating all relevant plots for this project.
   c. "working_with_particles" contains Jupyter Notebooks showing past & current progress on using the Symphony (and other simulation) particle-level data to create visualizations, etc.
   d. both "nadler-lab-summer-work" branches contain Jupyter Notebooks documenting progress over the summer of 2025 and 2026, respectively.
   
2. A document titled Research Portfolio, detailing my past projects, complete with small summaries of results and techniques. Some projects, such as the VCARRS project, have their own repository on my profile.
